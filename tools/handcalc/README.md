# 手計算用データの取得手順(オーナーのパソコンで一度だけ)

較正の手計算(calibration_plan.md 第2節)に使うデータを、オーナーのパソコンで取得する手順。data_spec 第6節の例外として、較正のときに一度だけ行う。

## いつ行うか

実験器が手計算の銘柄を選び終えたあと(較正計画 第2-1節)。Claude が、選んだ銘柄コードと期間を入れた実行コマンドを用意して渡す。オーナーは、そのコマンドを貼って実行するだけでよい。

## 守ること

- 保存先は1つのフォルダだけにする。既定は、ホームフォルダの下の `jp-smallcap-calibration`。
- 取得したファイルと手計算の表は、会話にもリポジトリにも入れない(CHARTER 第8章)。
- Git のリポジトリの中のフォルダには保存できないようにしてある。
- 較正が終わったら、最後の「削除」を行う。

## 準備(初回だけ)

1. Python 3.8 以上が入っているか確かめる。
   - Windows:スタートメニューで「コマンド プロンプト」を開き、`py --version` と入力する。入っていなければ、Microsoft Store で「Python」と検索し、いちばん新しい Python 3 を入れる。
   - Mac:「ターミナル」を開き、`python3 --version` と入力する。入っていなければ、表示される案内に従って入れる。
2. このファイルと同じフォルダにある `handcalc_fetch.py` を、GitHub のリポジトリのページから、パソコンの「ダウンロード」フォルダに保存する(ファイルを開いて、右上にあるダウンロードのボタンを押す)。

## 取得

Claude が渡すコマンドを、Windows ならコマンド プロンプト、Mac ならターミナルに貼って実行する。形は次のとおり(銘柄コードと期間は例)。

Windows:

```
cd %USERPROFILE%\Downloads
py handcalc_fetch.py fetch --item 11110:2019-03-01:2019-08-31 --item 22220:2019-03-01:2019-08-31
```

Mac:

```
cd ~/Downloads
python3 handcalc_fetch.py fetch --item 11110:2019-03-01:2019-08-31 --item 22220:2019-03-01:2019-08-31
```

- API キーを聞かれたら、パスワード管理から貼り付けて Enter を押す。入力しても画面には表示されない。
- 画面には、銘柄ごとの行数と保存先だけが出る。行数は会話に書いてよい(市場データではない)。
- 取得するもの:株価四本値(指定した期間)と財務情報(開示日が期間の始まりの12か月前から、終わりの3か月後まで)。

## 削除(較正が終わったら)

Windows:

```
cd %USERPROFILE%\Downloads
py handcalc_fetch.py delete
```

Mac:

```
cd ~/Downloads
python3 handcalc_fetch.py delete
```

- `yes` と入力すると、保存先のフォルダごと削除する。手計算の表を同じフォルダに置いていれば、それも消える。
- 最後に表示される日付を Claude に伝える。Claude が STATE.md に記録する。
- `handcalc_fetch.py` 自体はデータを含まないので、残しても消してもよい。
