# 手計算用データの取得手順(Windows・PowerShell、一度だけ)

較正の手計算(calibration_plan.md 第2節)に使うデータを、オーナーのパソコンで取得する手順。data_spec 第6節の例外として、較正のときに一度だけ行う。

## いつ行うか

- 本番の取得は、次の2つが済んでから行う。
  1. Standard の契約後に、GitHub Actions から 2017年のデータが取れると確かめたこと(較正計画 第6節)
  2. 実験器が手計算の銘柄を選び終えたこと(較正計画 第2-1節)
- Claude が、選んだ銘柄コードと期間を入れたコマンドを用意して渡す。オーナーは、それを PowerShell に貼って実行するだけでよい。
- 下の「準備」は、その前にいつ済ませてもよい。

## 守ること

- 保存先は1つのフォルダだけにする。既定は、ユーザーのフォルダの下の `jp-smallcap-calibration`(例:`C:\Users\<名前>\jp-smallcap-calibration`)。
- 取得したファイルと手計算の表は、会話にもリポジトリにも入れない(CHARTER 第8章)。
- Git のリポジトリの中のフォルダには保存できないようにしてある。
- 較正が終わったら、最後の「削除」を行う。

## 準備(初回だけ)

### 1. PowerShell を開く

スタートボタンを右クリックし、「ターミナル」または「Windows PowerShell」を選ぶ。以下のコマンドは、すべてこの画面に貼って Enter で実行する(貼り付けは右クリックか Ctrl+V)。

### 2. Python を入れる

次のコマンドを実行する。Windows に標準で入っている winget(アプリのインストーラー)で、Python 3.13 を入れる。

```powershell
winget install --id Python.Python.3.13 -e
```

- 初めて winget を使うときは、利用条件への同意を求められることがある。`Y` を入力して Enter。
- 途中で「このアプリがデバイスに変更を加えることを許可しますか」と出たら「はい」。
- winget が使えないと表示されたら、ブラウザで https://www.python.org/downloads/ を開き、Windows 用のインストーラーをダウンロードして実行する。最初の画面で「Add python.exe to PATH」にチェックを入れてから「Install Now」を押す。

### 3. 入ったことを確かめる

PowerShell をいったん閉じて、開き直してから、次を実行する。

```powershell
py --version
```

`Python 3.13.x` のように表示されればよい。「認識されません」と出たら、パソコンを再起動してからもう一度試す。

### 4. スクリプトを保存する

ブラウザで GitHub のリポジトリを開き、`tools/handcalc/handcalc_fetch.py` を開く。右上のダウンロードのボタンを押して、「ダウンロード」フォルダに保存する。

### 5. 動くことを確かめる(データは取らない)

```powershell
cd $HOME\Downloads
py .\handcalc_fetch.py --help
```

使い方の説明が表示されればよい。

## 取得(本番、一度だけ)

Claude が渡すコマンドを貼って実行する。形は次のとおり(銘柄コードと期間は例)。

```powershell
cd $HOME\Downloads
py .\handcalc_fetch.py fetch --item 11110:2019-03-01:2019-08-31 --item 22220:2019-03-01:2019-08-31
```

- 「J-Quants の API キー」と聞かれたら、パスワード管理からコピーして、右クリックで貼り付け、Enter を押す。入力しても画面には何も表示されない。
- 画面には、銘柄ごとの行数と保存先だけが出る。行数は会話に書いてよい(市場データではない)。
- 取得するもの:株価四本値(指定した期間)と財務情報(開示日が期間の始まりの12か月前から、終わりの3か月後まで)。
- 保存されたファイルは、エクスプローラーで保存先のフォルダを開くと見られる。CSV は Excel で開ける。手計算の表も、このフォルダに置く。

## 削除(較正が終わったら)

```powershell
cd $HOME\Downloads
py .\handcalc_fetch.py delete
```

- `yes` と入力すると、保存先のフォルダごと削除する。手計算の表を同じフォルダに置いていれば、それも消える。
- 最後に表示される日付を Claude に伝える。Claude が STATE.md に記録する。
- 削除したフォルダはごみ箱に入らずに消える。
- `handcalc_fetch.py` 自体はデータを含まないので、残しても消してもよい。
