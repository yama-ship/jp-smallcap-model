# 日本中小型株モデル プロジェクト

オーナー1人とClaudeで運営する、投資モデルの研究と運用のプロジェクト。

- このリポジトリは、研究の原本。
- 約定・保有・余力の原本は楽天証券の記録で、ここにあるのはその写し(CHARTER 第9章)。

## 最初に読むもの

1. STATE.md:今の状況
2. CHARTER.md:最上位のルール(第6章と第7章は毎回読む。ほかの章は必要に応じて読む)
3. 作業する実験の experiments/EXP-xxxx.md

## 構成

- **CLAUDE.md**:作業するClaudeへの指示(自動で読み込まれる)
- **CHARTER.md**:憲法(目的、オーナーの条件、リスク上限、採用条件、停止条件、権限、データの取り決め)
- **STATE.md**:現在の状況、オーナーへの質問、未解決の事項、次の行動
- **decisions.md**:決定ログ(追記のみ、決定者つき)
- **experiments/**:実験記録(1実験1ファイル。アイデアから引き継ぎまで)
- **papers/**:論文カード(検証に進む実験の根拠と反証だけ)
- **project_instructions/review.md**:審査用プロジェクトの指示と、審査を頼むときの定型文

### あとから追加するもの

- フェーズ1:data_spec.md、holdout_log.md、core/(実験器の核)、runs/(自動出力)、.github/workflows/
- フェーズ2:live/(売買台帳、照合)

## ここに置かないもの

- 市場データの本体と、元データを復元できる派生物(銘柄別・日別の価格やリターンの表など)。置けるのは集計指標だけ。
- 認証情報
- 勤務先の取引先に関する情報
